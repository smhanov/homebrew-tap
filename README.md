# smhanov/tap

Homebrew tap for [squint](https://github.com/smhanov/squint) — review
what your LLM just committed, in a terminal UI.

```sh
brew install smhanov/tap/squint
```

The cask is updated per release; goreleaser will automate the update
once a fine-grained PAT (`HOMEBREW_TAP_GITHUB_TOKEN`) is configured as
a secret on the squint repository.
